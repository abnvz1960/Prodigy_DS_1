# Prodigy_DS_1
Data visualization of student performance data using a bar chart (gender distribution) and a histogram with KDE (math score distribution) in Python. Prodigy Infotech Data Science Internship, Task 1.
# Task 1: Visualizing Student Data

Part of the Prodigy Infotech Data Science Internship.

## Objective
Create a bar chart and a histogram to visualize the distribution of a
categorical variable (Gender) and a continuous variable (Math Score).

## Dataset
Student Performance dataset (CSV).

## Approach
- Loaded and explored the data (shape, info, column names)
- Checked and dropped missing values in the target columns
- Bar chart (countplot) for gender distribution
- Histogram with KDE curve for math score distribution

## Tools
Python, Pandas, Matplotlib, Seaborn

## How to run
1. Download the dataset and update the file path in the notebook
2. Open `Prodigy_Task1.ipynb` in Jupyter or Google Colab
3. Run all cells
